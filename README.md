# GroupDNA – WhatsApp Chat Analyzer

A Python-based WhatsApp chat analytics project built using **Python Fundamentals + NumPy**.

## Project Overview

GroupDNA analyzes exported WhatsApp group chats and generates meaningful insights such as participant activity, busiest hours, response patterns, favourite words and personality archetypes.

This project was developed as **Week 1 Minor Project** for **The Unlox Academy**.

## Features

- WhatsApp Chat Parser
- Group Overview Dashboard
- Most Active Day & Peak Hour
- NumPy Activity Heatmap
- Top 10 Favourite Words
- Response Time Analysis
- Silent Streak Detection
- Personality Archetypes
- Final Console Report

## Technologies Used

- Python Fundamentals
- NumPy
- datetime

## Constraints Followed

- No Pandas
- No Matplotlib
- No Regex
- No Counter
- No WordCloud

## Dataset

- `hostel_bois.txt`

## How to Run

1. Open the notebook in Google Colab.
2. Upload `hostel_bois.txt`.
3. Run all cells from top to bottom.
4. The final GroupDNA report will be generated.
